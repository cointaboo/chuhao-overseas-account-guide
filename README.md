# 海外账号选购手册：不同平台，挑法完全不同

> 买海外账号踩坑，多数不是因为买到假货，而是**用同一套标准去挑不同平台的号**。
> Telegram 号要看的东西，跟苹果 ID 要看的东西，根本不是一回事。这份手册按平台拆开讲。

## 一、为什么"通用挑法"不成立

市面上的避坑文章常给一堆通用建议：看价格、看评价、看售后。这些都对，但**太粗**。

真正的差别在细节：
- Telegram 号的核心风险是 **被原主找回**（因为手机号还在原主手上）
- 苹果 ID 的核心风险是 **地区不符 / 无法改密保**
- TikTok 号的核心风险是 **实名状态 / 设备绑定**
- 推特老号和推特新号，价值能差十倍

所以挑选标准必须按平台来。下面逐个拆。

---

## 二、Telegram（飞机号）怎么挑

问商家这四件事：

1. **注册时长 / 号龄**——注册越久、有正常聊天记录的号越"干净"，不容易被风控秒封。
2. **是否已设两步验证（2FA）**——好的货一进来就是带 2FA 密码交付的，你拿到就能自己改。
3. **手机号能否改绑**——这是最关键的一条。**手机号还在原主手上 = 原主随时能找回**。
   能改绑的号，安全性完全不是一个级别。
4. **是否绑定过设备 / 有无异常登录记录**——卖家若能说明，通常说明他有真实养号能力。

**警惕**：只发一串验证码让你自己登录、不给 2FA 密码、说"改绑要加钱"的，基本是把风险留给你。

---

## 三、苹果 ID 怎么挑

苹果 ID 的价值几乎全在**地区和支付能力**上：

| 关注点 | 说明 |
|---|---|
| **地区** | 美区 / 港区 / 日区 / 土区，用途完全不同。买之前先确认你要下什么 App |
| **是否绑定支付方式** | 绑定过的号能直接内购，但**也可能被原主挂失卡片** |
| **能否改密保 / 改邮箱** | 拿到手第一件事就是改，改不了的号等于租的 |
| **是否带账单地址** | 有完整账单信息的号更"像真人"，被封概率低 |

**别信**"永久可用"这类说法——账号能不能长期用，取决于能不能改成你自己的信息。

---

## 四、TikTok 怎么挑

TikTok 号分两类，价值天差地别：

- **纯白号（新注册）**：便宜，适合自己从零做内容
- **有粉丝 / 有历史的号**：贵，适合需要冷启动流量的

看这几点：
1. **地区**（环境归属，影响视频推荐池）
2. **是否已实名**
3. **能否换绑手机 / 邮箱**
4. **有没有违规记录**（有记录的号限流）

---

## 五、推特 / X 怎么挑

推特最看**号龄**：

- **老号（注册 1 年以上）** 权重高、发帖不容易被限、更"抗封"
- **新号** 便宜，但发推广内容极易触发风控

另外确认：**邮箱是否可以改**、**有没有绑手机**、**有没有历史发帖记录**。

---

## 六、ChatGPT / AI 账号怎么挑

AI 类账号的核心是 **套餐类型**，不是价格：

- **Free / 普通号**：能用，但模型和额度受限
- **Plus 订阅号**：能用最新模型，但要看**是独享还是共享**——共享号随时可能被挤下线或改密
- **是否需要你自己配环境（IP / 地区）**：这点商家通常会说明

**关键问题**：这个号是**独享**还是**拼车**？共享号的价格低，但你要接受随时失效。

---

## 七、短信接码怎么挑

接码是"用完就扔"的服务，但质量差别很大：

1. **号段来源**——真实运营商号段比虚拟号段通过率高得多
2. **是否支持重复收码**——只给一次码的，平台二次验证时就废了
3. **目标平台是否支持该号段**——下单前先问清楚
4. **超时退款规则**——收不到码能不能退

---

## 八、三条通用原则

不管买哪种号，这三条都成立：

1. **优先选一手货源**。二手转卖的号，环节越多，风险越大——你不知道中间经了几手手、有没有被复制。
2. **优先选卡密自动发货**。人工发货意味着中间有人能看到你的号；自动发货是系统直出，链路更干净。
3. **看清楚售后标准**。包换期几天、什么情况包换、怎么联系——写得越具体，通常越靠谱。
